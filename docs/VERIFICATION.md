# 검증 기록

환경: Apple M4 Pro, 메모리 48 GB, macOS 27.2.1, Swift 6.4.2.

## v0.4.0 폴더 구조와 LLM 용어

- 소스를 App·Audio·Transcription·Input·UI·Diagnostics로 구분했습니다.
  코어 검사는 `Tests/VoicePromptChecks`, 문서는 `docs`, Finder 실행 명령은
  `scripts/launchers`, 이미지 원본과 앱 리소스는 각각 `assets/branding`과 `Resources`에 둡니다.
- SwiftPM 검사 대상, 번들 리소스 복사, 아이콘 도구, 문서·실행 명령의 상대 경로를 수정했습니다.
- WhisperKit 1.1.1 로컬 소스의 `promptTokens` 처리와 특수 토큰 제외 동작을 확인하고
  모델명 힌트를 연결했습니다. 설정에서 끄기와 추가 용어 입력을 지원합니다.
- 표기 보정은 Qwen 이름·모델 버전·파라미터 크기를 다룹니다. 일반 소수, 코드,
  URL, 저장소 식별자와 파일명, 원래 단어가 바뀌지 않는 경우도 회귀 검사에 포함했습니다.
- 공식 문서에서 확인한 기본 용어 23개를 추가했습니다. Ollama·RAG 표기, Qwen2,5의
  버전 표기, 일반 영어 단어와 Ollama 실행 명령 보존도 검사합니다.
- 최종 코어 검사 128개 통과. Release 컴파일, 임시 번들 패키징과 서명 무결성,
  셸 문법, 아이콘 도구 타입 검사, 문서의 로컬 링크 및 실행 명령의 기준 폴더 확인을 통과했습니다.
- 음성 정확도 향상률은 아직 실측하지 않았습니다. 문자열 보정 검사와
  실제 음성 인식 품질은 별개이며, 추가 용어는 인식을 보장하는 강제 출력이 아닙니다.
- `--verify-only`는 고정 인증서 키체인 없이 임시 앱의 Release 컴파일·리소스 패키징·
  ad-hoc 서명 무결성을 확인합니다. 현재 설치된 v0.3.1은 이 검사로 교체하지 않습니다.

## v0.3.1 단축키 입력 검증

- 현재 저장된 조합이 `⌃⌘Space`임을 확인했습니다. 이 조합은 macOS의
  이모지·기호 창 단축키입니다. 또한 이 Mac의 시스템 단축키 설정에
  `⌃Space`, `⌃⌥Space` 입력 언어 전환이 활성화돼 있음을 확인했습니다.
- 기본 조합을 `⌃⇧Space`로 변경했습니다. 시스템 단축키 충돌을 확인하고,
  기존 설정이 충돌하면 백업 후 추천 조합을 등록하며 변경을 안내합니다.
- 기존 `held` 집합은 키 해제 이벤트 하나가 빠지면 다음 누름도 계속 무시했습니다.
  Carbon 누름 이벤트를 직접 처리하고 이벤트 시각으로 중복·오래된 이벤트만 걸러냅니다.
- Carbon 핸들러가 메인 스레드에서 순서대로 처리하도록 변경했습니다.
  핸들러 설치 오류, 이벤트 서명·ID, 등록 결과를 검사합니다.
  독점 등록으로 다른 앱과의 충돌을 확인하고 새 등록이 성공한 뒤 기존 등록을 해제합니다.
- 코어 검사 43개 통과. 단축키 충돌, 키 해제 누락, 연속 100회 누름,
  중복·역순 이벤트, 독립적인 취소 이벤트 검사를 포함합니다. Release 컴파일 성공.
- `--check-hotkeys`로 실제 Carbon 등록과 앱 내부 이벤트 전달 검사를 추가했습니다.
  자동 실행 환경에서는 전역 등록이 `eventInternalErr(-9868)`로 실패했습니다.
  이 결과는 아래 사용자 세션 검증과 구분합니다.
- 앱 화면 제어도 시간 초과로 실패했습니다. 설정에 녹음 없는 **단축키 검사**와
  수신 횟수를 추가해 사용자 세션에서 확인할 수 있습니다.
- 고정 인증서 키체인 잠금 해제가 자동 실행 환경에서 실패했습니다. 이후 사용자 세션에서
  업데이트가 실행돼 설치 앱 버전이 v0.3.1로 변경된 것을 확인했습니다.
  빌드는 서명·검증을 임시 폴더에서 마친 뒤에만 기존 앱을 교체하도록 변경했습니다.

- 2026-11-16 20:06 사용자 세션의 `var/qa/hotkey-check.txt` 확인: 시스템 단축키 135개 조회,
  추천 조합 충돌 없음, Carbon 통합 검사 15개 및 연속 이벤트 100/100회 전달 통과.
  물리 키보드 5회 입력 결과와 실제 음성 정확도는 별도 확인 대상입니다.

참고: [Apple 단축키 안내](https://support.apple.com/en-mide/102650),
[KeyboardShortcuts](https://github.com/sindresorhus/KeyboardShortcuts).

## v0.3.0 미리보기와 권한 처리

- 다음 디코딩이 짧은 첫 단어부터 다시 시작해도 이전 문장을 지우지 않습니다.
  빈 중간 결과와 뒤늦게 온 짧은 콜백을 무시하고, 완료된 결과의 교정은 반영합니다.
- 미리보기를 380 × 252pt로 줄였습니다. 네이티브 텍스트 뷰를 유지하며
  화면 반영을 초당 최대 10회로 묶고, 줄이 늘어날 때만 하단 스크롤을 따라갑니다.
- 권한 없는 AX 조회를 막고 시스템 권한 요청 팝업을 한 번만 호출하도록 변경했습니다.
  설정에서 허용한 권한은 1.5초 간격으로 확인해 화면에 반영합니다.
- 기존 앱의 서명은 ad-hoc이며 지정 요구사항이 실행 파일 해시에 묶여 있음을 확인했습니다.
  프로젝트 전용 인증서와 고정 요구사항을 사용하는 서명·재실행 도구를 추가했습니다.
- v0.3.0 Release 빌드, 22개 코어 검사, 코드 서명 무결성, Info.plist와 셸 문법 검사를 통과했습니다.
- 자동 실행 환경의 키체인 생성이 실패해 현재 배포 앱은 아직 임시 서명입니다.
  `scripts/launchers/VoicePrompt 권한 고치기.command`를 사용자 세션에서 실행한 뒤 인증서 서명과
  권한 유지, 실제 화면의 전환을 확인해야 합니다. 고정 서명 적용 완료로 간주하지 않습니다.

## 자동 검증 환경의 제한

컴퓨터 사용 도구의 ScreenCaptureKit 오류로 화면 캡처 검증을 완료하지 못했습니다.
독립 UI 렌더링도 현재 실행 샌드박스에서 AppKit 초기화 단계에 종료되었습니다.

공개 Google FLEURS 한국어 음성으로 추론을 시도했으나 현재 실행 샌드박스에서는
WhisperKit의 IOSurface 기반 MLMultiArray 할당이 실패했습니다. CPU 지정 시에도
SDK가 같은 메모리 경로를 사용해 실패했습니다. 따라서 자동 측정한 정확도·속도나
실시간 지연 수치는 아직 없습니다. 사용자가 직접 실행한 앱의 결과와 구분합니다.

검사용 음성 출처: https://huggingface.co/datasets/google/fleurs (ko_kr / dev).
검사용 파일은 `var/qa`에만 두며 배포 앱에 포함하지 않습니다.
